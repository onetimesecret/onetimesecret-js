# Code of Conduct

This project is small and so is its community. The rules are correspondingly
short.

## Expectations

- Be respectful. Disagree with ideas, not people.
- Keep discussion on the work: issues, pull requests and reviews are about
  the code and the documentation.
- Assume good faith. Most friction is a misunderstanding; ask before
  concluding otherwise.
- Harassment, discrimination, personal attacks and publishing someone's
  private information are not tolerated, in any project space or when
  representing the project elsewhere.

## Reporting

Email **support@onetimesecret.com** with what happened and where. Reports are
read by the maintainers, handled privately and answered within a few business
days. Security problems go to the address in [SECURITY.md](SECURITY.md)
instead.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests
that break these rules, and may temporarily or permanently exclude anyone
whose behaviour does. Decisions are explained to the person concerned.

This document is adapted, with the wording shortened, from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
